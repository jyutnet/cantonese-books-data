關於本書
--------
《分部分音廣話九聲字宗》是一本 1914 年出版的粵語韻書，特色如下：

* 早年由華人所撰之粵音字彙，成書在《粵音韻彙》之前，比《道漢字音》、《民眾識字粵語拼音字彙》更早，極具歷史價值。
* 早期字典，如《初學粵音切要》(1855)、《英華分韻撮要》(1856) 仍按傳統只區分上入、下入，此書則有區分中入聲。
* 除了按各聲韻的發音特徵分組，更有文字描述聲、韻、調的發音方法和特性。
* 粵語讀音是多人商討下的成果，而參與者都是文化人，注音有參考價值。
* 印證好些今日慣用卻被視為錯誤的粵語讀音的歷史。例如「糾」讀［斗］、「擴」讀［曠］、「龕」讀［菴］，從此書可見，原來百多年前已為知識界習用。

有關本書的音系解說和書影請參閱本書[典籍專頁](https://lee1914.jyut.net)。

## 李淡如 (1859-1942)

李淡愚，曾作淡如，名春華，新會縣七堡區人，居住會城鎮。1859 年生，少時家貧，唯天資聰穎，性剛強，肯讀書，從小就喜愛楹聯，得到邑中名宿、舉人吳鐵梅的器重，命就館攻讀，學有所成後，開始從事教育事業。

1908 年，李淡愚與何琴樵在會城蘊華學堂任教，並一同兼任香港《華字日報》特約撰述員。

1912 年，為便於教學，李淡愚把同音字 6000 多個分別「九聲」編印一冊《分部分音廣州話九聲字宗》刊行，以供學堂教師講課之用。不久，李淡愚又與林仲肩編著《省話九聲古詩》。選用古詩二三十首，每個字旁都附有齊、開、合、撮以及屬第幾聲的符號，使學生從小就學會用廣州話讀書、說話。

李淡愚不僅研究廣州話，而且對北京話（普通話）也很有研究。早歲，他是「全國讀音統一研究會」會員，曾出席我國著名的語言學家玉璞主持的「讀音統一會議」，對拼音和聲調多有建議。

從前，上海商務印書館出版的《新字典》均以「反切」注音，每個字有時用幾種「反切」，很難理解。李淡愚特去函提出改進意。後來商務印書館請他往上海，商討並接納了他的意見，將該書的「反切」整理好，並改稱為「實用字典」。

當時，李淡愚能精心研究語言學，做到言傳身教，推行說廣話、北京話，開風氣之先，是十分難得的。

從 1909 年至 1911 年清末宣統年間，李淡愚與林仲肩、李吉甫、吳孝遂在會城西隅街關氏祖祠開辦文約學塾（即學校），自任塾長。那時，一般學校還是按舊的內容和方法教學的。但文約學塾不僅教學方法新，而且課程也新，設有「講報章」課程。所謂「講報章」也就是講時事。他把何琴樵創辦的新會《醒報》作為教材，先叫學生抄好報上的新聞，然後上課講授。李淡愚能接受新潮流、新思想，為社會先導的精神實在難得。其他如教寫日記、教國音、教省話，是考慮到兒童實際需要。他在教學中還運用獎勵方法，對在教學上有顯著成績者給予獎勵。李淡愚講課，常抨擊清政府壓制民權、懦弱無能、辱國喪權，學生在他的新思想影響下，在作文卷末的年月日中不填「宣統」年號，而填為西元年月，有的還填上「天運元年」字樣。其意為已推翻清政府，改換年代了。

1911 年辛亥革命後，李淡愚眼見新會兒童大半由於家貧，沒有條件就學。於是，他就決心通過動員新會華僑出資辦學，來解決這個問題。

1916 年，李淡愚從加拿大域多利講學回來，就大力向港商宣傳，鼓勵他們出資創辦貧兒義塾。1917 年，在他的策動下，港商馮平山設立了「平山義塾」，在新會開創義務教育之先河。隨後，相繼在會城開辦的有南洋義塾、晴江義塾、俊偉義塾、澄波義塾；還有在七堡開辦的藝池學塾、亦梅義塾；在梅岡開辦的壽南義塾、在陳沖開辦的澄波義塾。此外，新會的善堂也辦善塾了，像愛群善院，就開辦仁愛義塾、永存義塾。港商陳瑞祺除在新會開辦四間義塾之外，還斥資在廣州、佛山、開平、香港等地，同時開辦澄波義塾不下二十間。

這些義塾，為吸收家境清貧的兒童入學，完全不收學習費用。書包、書籍、紙、筆、墨等應用文具亦由義塾供給。在義塾學習的兒童，既能學到基本知識，又能養成勞作的良好習慣。義塾特別注重書法以及尺牘、珠算等職業準備課，更訓練兒童以國語、省話講演，以適應時代要求，還培養兒童識字、明理、會計數、能吃苦的本領，使他們將來易於找到職業。李淡愚還喜歡獎掖後進，對貧寒子弟更是關心、照顧。李香介早年在李淡愚塾中讀書，因家貧半途要求輟學，李淡愚知道後，即免其學費，並安慰一番。李香介十分感動，益加勤奮向學，當年考上秀才。

李淡愚倡辦的義學，前後二十年，收失學兒童達數萬人。經過義塾培養出來的學生，大都能踏踏實實、勤勤懇懇工作，成績顯著。數十年間，李談愚除任會城多所義塾塾長之外，先後兩任私立岡州中學校長，挑李萬千。

李淡愚身任多所學校校長期間，聘用教師甚多，都能擇其優者而用之，從不任人唯親。據一位當年曾受聘用的陳雲淪老師說：一日，淡愚遇見他，笑問道陳是陳ＸＸ嗎？明天到這裡來，給你考試。」陳問何故？李淡愚直言說，某校請教師，如考試合格可往任教。陳依時而往，李淡愚即以四年級國民課本讓陳上堂講授，他則旁聽。陳講課時，語多詼諧，學生大悦，他則邊聽邊點頭。事後，李淡愚對陳說：「你講得不錯，比我笑料還多，可等候聘用。」

李淡愚還嚴格要要求每個老師熟習《省話九聲古詩》，以便用廣州話講課。至於那些不求甚解的教師，他一經發覺，即予解聘，毫不留情。

李淡愚熱心教育，除首創義塾之外，還利用他的影響，積極發動社會各界人士捐款修建校舍。前廣東高等師範學校（今廣州市魯迅紀念館館址，中山大學前身），欲建教學大樓，需款十萬，苦無經費。李淡愚就發動港僑，並表示誰捐資築樓，就以誰的名字命樓名。馮平山知道後，寫信徵求李淡愚意見。李即覆函鼓勵，事得以成。馮氏除捐資十萬元建築「平山堂」作為教學大樓之用外，還另捐二萬五千元給學校，作學生獎金。

1930 年，李淡愚第二次出任岡州中學校長時，以岡中校舍日久失修為慮。1933 年的一天，適值號稱百萬富翁的旅澳歸僑岑日初設宴於岡城酒樓，李淡愚應邀而往。賓主觥籌交錯，很是高興。李淡愚便乘機以校舍失修事相告，請岑氏捐款。岑先認一萬，再經李勸告後，將一萬的一字加多一豎，變為十萬。是夜，李淡愚一面擬好新聞稿發給江門會城各報刊登，一面親自撰寫了一副對聯，用相架裝好送往岑府。聯云：「栽培弟子千百輩，敬請先生十萬金。」第二天早上岑日初捐款興建岡州中學校舍的報刊消息，很快轟動全縣，一時傳為美談。校舍落成後，校內為岑父公餘立有銅像，並在校門簷下由李淡愚親筆題有「岑日初先生捐款十萬元」的石刻，以留紀念。

李淡愚對社會福利、國計民生等事盡力而為，造福大眾：清光緒三十四年（1898 年），會城鼠疫流行，日死百餘人，人心惶惶，貧者無以為殮。李淡愚向殷商富戶募捐施棺三千餘具，邑人感之。

1914 年，新會縣陳沖與羅坑兩鄉發生「陳林械鬥」。李淡愚排解無效，也已盡力。古井「吳越械鬥」，李淡愚以古井文樓為其師吳鐵梅的家鄉，特親自出任調停，經多方奔走，事才稍息。

會城原無公園遊覽。李談愚大力發動各界人士，出錢出力興辦公園。考慮到會城象山曾是新會明代學者張撝開辦「象山書院」的舊址，又是新會八景之一（象山秋月），遂負起興建「象山公園」的重任。他在 1917 年至 1924 年間，先後發動港商馮平山捐築養拙亭，李藝池捐築秋月臺，省財政廳長、邑人楊西岩重修「海月奇觀亭」；縣長吳風聲捐款修築山路。所有碑文由李淡愚題記。李淡愚還發動何琴樵等捐築「仰湲臺」以紀念其師黎壁湲，李香介等捐築仰山亭以紀念其師林仲肩。李淡愚自己也出資建築「鐵梅臺」，在臺上矗立着圓石柱，正面刻上「李淡愚為吳鐵梅夫子紀念」。後面用鐵水鑄成一枝梅花，以紀念其師吳鐵梅。通過一連串的努力，新會群眾自覺修起半山亭、亦臺，建牌坊、挖池塘、植樹造林等，使象山公園成為會城群眾一個好去處。

在同一期間，李淡愚又在江門白沙鄉附近（江會公路旁）倡建「白沙公園」以紀念明代大儒陳白沙先生。他先後發動馮平山、陳瑞祺、李藝池等出資建築嘉會亭等幾座亭台。並築池、疊石、栽花植樹，四周圍以窗牆，使之成為遊覽憩息的好地方。

建設圭峰山，李淡愚更是積極參與。1920 年，李淡愚便發動旅越僑胞譚雨蒼，捐款興建「白沙講學亭」，並建築「四君台」及吳鐵梅、林仲肩、關兆源三君墓於講學亭下，以點綴名山勝景。李淡愚對新會能做出那麼大的成績，主要是勇於任事、有魄力，責任心強，甘當「社會之僕」（他以此四字刻有印章）。加上他明道理，善辭令，深得海外華僑、港澳同胞、社會人士的尊敬和信任。

李淡愚人格高尚，性品善良。他一生儉樸，不貪不謀，廉潔自持。他對殷商巨賈、達官貴人，既不諂媚，也不奉承。他常用兩句成語當作處世格言，亦作為自己行為的標準，即：「不亢不卑，若即若離」。表示他對人既不驕橫傲慢，也不奴顏婢膝；既像親近又像疏遠。在平山小學任校長時，馮氏給他年薪六百元，他只要三百元。1930 年，霍堅接任新會縣長，以其妻李月華曾在域多利受業于李淡愚之門，霍縣長剛就任就與妻子到李淡愚家拜訪。次日，就委任李淡愚為縣教育局長。李淡愚卻親自將委任狀送回去之。經再三敦請，均婉辭不就。平時，李淡愚喜歡用價廉的紫花布做衣服，曾刻有「紫衣道人」的印章。幾十年間，李淡愚沒置田立業，連房子都是租賃的。他的妻子女兒，長年在家做家庭手工業──削製葵骨牙籤來彌補生計，用小紙盒裝着出售，盒上印有「挑剔不玲瓏，必有蛙牙蟲」兩句話。

李淡愚性獨嗜酒，日飲數次。飲酒後或笑或罵，人多畏之。加上因不趨時俗，與眾不同，難免招致一些人嘲諷。但他坦然處之，繼續積極為公益事業操勞。有人稱他為「象山怪物」。他以此四字刻成印章，還隨處使用。

李淡愚一生另一成就，就是工於對聯。其師贊之堪與番禹何淡如相媲美（何淡如，四十二歲中舉人，曾任高要縣學教諭，所作對聯用詞巧妙，雅俗兼備，奇趣幽默，備受推崇）故李淡愚自號為李淡如。二十四歲時，隨師作郊外遊，見花橋亭龍溪廟有門聯云：「此地得崇山峻嶺清流諸勝；其俗有孝友睦姻任恤之遺。」下款只寫「里人李春華書」。吳鐵梅就問何以無作者姓名，因此聯是李淡愚自己初次學作，所以當時李淡愚只含糊以對，未敢承認。後來，吳謂聯中能運用「勝地」、「遺俗」四宇，似是老手。李淡愚始直認不諱。

吳鐵梅早年曾在北京的新會館陳白沙先生肖像撰有一聯云：

>五百年名代更生，黃雲紫水；<br>
>八千里家鄉風味，葵綠橙黃。

後來，吳鐵梅身故，葬於新會圭峰玉台寺左側嶺上，李淡愚為之撰墓聯云：

>此地有黃雲紫水，其人如鐵樹梅花。

這副聯，李淡愚既承師句，又巧妙地將老師之名嵌入聯中，時人稱絕，有青出於藍而勝於藍之譽。

數十年來，李淡愚的聯語，所作甚多，莊諧雜出，語意雙關。如清末戊戌年間，李淡愚寓居香港，赴友人為一青樓女子（名雙鳳）脱籍之宴於「醉瓊樓酒家」老闆素聞李淡愚之名，出紙索書對聯，友人復要求聯中切合今夕之事，李淡愚想起當時英國政府正向清政府索租九龍，勘地劃界，便揮筆寫聯語云：

>醉酒倩人扶，大開李白喉嚨，有客醉攜雙鳳去；<br>
>瓊林開夜宴，可有狄青手段，三更奪得九龍回。

聯中既嵌入酒樓和青樓女子的名字，又切中時事，聯語相關，老板和東道主皆大歡喜，讚不絕口。
李淡愚用俗語作對聯很多，如在六十七歲生日那年作了一對：

>可以笑人腳趾曲，不妨作事心頭高。

俗語說「未到六十六，唔好笑人腳趾曲」。李淡愚已六十七歲就可以笑人腳趾曲了。他寫的俗語對聯還有「眾事莫理，眾地莫企；有錢學散，無錢學慳」。又如「薄待先生，天誅地滅；誤人子弟，雷打火燒」等，都是運用俚語連成的。

李淡愚的聯風，寓莊於諧，寓教於虐，針眨時弊。有一天，李淡愚與文士林文聰煮酒論文，林出上聯：「童子打桐子，桐子落，童子樂。」李淡愚低頭思索，見林穿着一雙新布鞋，使靈機一動作對：「孩兒穿鞋兒，鞋兒寬，孩兒歡。」

李淡愚還寫了一些破除迷信，痛斥當時官場腐敗的對聯，如：

>經典可消災，難道閻羅怕和尚？<br>
>紙錢能活命，分明菩薩作贓官。

李淡愚在會城城東財神廟寫有如下聯語：

>頗有幾分錢，你也求，他也求，給誰是好？<br>
>不做半點事，朝來拜，暮來拜，叫我如何。<br>
>袞袞諸公，牛公馬公，公然辦公，公心何在，公道何在？那項假公非利己？<br>
>堂堂當局，左局右局，局了又局，局內者甘，局外者苦，幾時結局不傷人！

李淡愚的酒樓對聯也聞名於世。民國初年，李淡愚應聘赴加拿大域多利埠華僑公校任教，因為他博識廣聞，所以經常有茶樓酒館請他寫對聯，以光門面。當時有一家「北京酒家」在華埠頗負盛譽。李淡愚用了「鶴頂格」聯嵌「北京」兩字於其間，妙語天成，不留一絲刀痕斧跡，其聯云：

>北美駐遊蹤，在我儕把酒論文，明知飯碗問題，食飯撞鐘，忙裏須求新教育；京華多怪狀，歎若輩偎紅倚翠，只抱金錢主義，黃金買笑，醉來忘記舊山河。

此聯，李淡愚把隱諷發揮到淋漓盡致。

李淡愚在崖山、圭峰、白沙、象山等遊覽區所作的楹聯也不少，其中如崖山慈元殿聯云：

>魯連蹈海，弗肯帝強秦，矧一塊肉僅存，那堪滿地干戈，白雁忽來再被虜；<br>
>漢武築台，尚思戾太子，問六尺孤何托，料得兩崖波浪，黃泉相見不勝悲。

李談愚在圭峰山玉台寺的聯云：

>我佛本慈悲，忍看寡婦孤兒，與丞相皆亡，不為援手；<br>
>名山多鐘毓，為問黃雲紫水，後白沙繼起，可有異人。

李淡愚愚少時性躁，其師鐵梅曾賜以「佩韋」之號，取其以柔制剛之意。李受之，自號「佩韋居士」並刻有「佩韋」印章時加警惕。

1938 年，日軍侵入華南地區，戰火蔓延到新會，李淡愚的子孫多族居香港，因而李淡愚便赴港與家人團聚，以度晚年。後四年，因病卒於香港，享年 84。著有《省話八聲七絕》、《分部分音廣州話九聲字宗》、《省話九聲古詩》、《李淡愚先生聯語錄》等書行世。

# 序

中國文字，數逾十萬，聲字分歧，各不相屬，誠世界上最煩難者也，歐美文字，類多以字母拼音，字聲相依，識其音者可拼得其字，實至簡便易記，而中文異是！每有曾識其字，記其音，而偶爾疏用，一旦握管，輒忘焉不能下筆；音則琅琅在口，字則模糊於心，雖腦竭腸枯，百思不得，茫茫字典，下手無從，此普通人士所常感之困難也！吾屢欲編一檢字善本，然苦無良法；且人事日紛，着手非易；參考搜集，必賴多書，是以徒有此心，迄未成事。或有舉市上分韻撮要以對者；然吾觀是書，繁雜異常，檢查不便，往往費時半句鐘，猶未得其字者，又何取也？且此書古僻之字，觸目皆是；最通行者，乃反掛漏，科學新奇之字，更無論矣，數年以來，未有愜意者！乃者劍言旋香島，拜訪馮丈師韓，馮丈滑稽善談，無所不達，出入中西，證據今古；尤為字學耆宿，閨秀名流，願得而師事者：遍乎大江南北；晚年息影香島，以著述自娛：有《書法相人術》，《半畝竹園隨筆》，《書法闡微》行於世；見識深造，思想新穎，近著粵音依聲檢字，行將付梓，巧劍之來，出以相示，劍初耳其書，若有解悟；及得拜讀，正償夙願，蓋先得我心，先書我手矣。斯編祇以英文字母十七個，檢得中字達七千，自化學名詞以至粵東俗字，凡通行應用者，包羅幾盡；至于古僻之字，一概刪除；注釋示例，力求明簡，務能一覽可獲，信手即得，不特此也；此書對于中字併英，尤有功匪淺，街名人名，併字應有定規；而粵東人士，每各逞土音，亂拼英字，甲此乙彼，混 ch 為 ts，言人人殊，不便孰甚！此書一出，吾知併音之法，可趨劃一矣，至於應用方法，自不難學；識英文者祇看三分鐘說明，不則但學半句鐘拼音，即可運用自如，檢閱隨意，老耄善忘，及士商各界允宜人手一編，勝對良師問字，劍既欣得檢字易法，又覩併音良規，故樂為序言，以興來者。

莫慧劍  一九三五，七，八

# 自序

恒人之情，每志於大而略於細，慮乎遠而忽乎邇，是故日常習於耳目之事，其真諦或有未悉焉，夫吾人廁身香㠀，除少數渾沌無知者外，其於㠀之沿革鮮有不諳其梗概者，惟於香㠀之㠀字，能知其从鳥者寡矣，此蓋習焉而不察有以致之耳，且字亦有正俗之分，一弗措意，雖通人猶不免貽人口實，（一）如廚之从广，戲之从豆，豔之从盍，䜿之从豆，憩之从自，麫之从丐，致之从夂，臯之作皋，旁之作㫄，肅之中多一橫筆，从聿而實入聿部，（二）又如厯之代歷，㝉之代宁，元玄之代玄，燁𤑼之代燁，允胤之代𠉥，正禎之代禛，𡩋之代寧，皆避前廟諱而作如是書者，（三）又有轉字之音以作避諱者，如正字讀作征音，及甄別之甄字，本音堅，因三國時江左諸儒避孫堅諱，改讀真音等等，凡此等字，雖沿用已久，然亦當知其致是之由也，是編於此三者，頗為留意，惟主旨則（一）耑備識字之人於悤遽中檢查遺忘之字者，但於日用之字，其形之易於淆亂者，則加以注釋，俾易觀覽，（二）紙之篇幅，多留空白，以便讀者隨時按字之聲，自行增補，（三）所列羅馬併音法，欲以便治說文者將字編入書內，以便查檢，（四）所附土白，耑為略識之無之婦孺而設，是編之作，明知不值通人一覽，惟於剎那間，能檢出所需之字，亦一大快事也。

民國廿四年八月	鶴山馮　漢識

# 例言

鶴山馮　漢師韓編纂

- 執筆忘字人有同情，是編特仿泰西以聲檢字法，無論筆畫之類音義之異，雖偶爾遺忘，祇知其音，便可查檢。
- 前讀書統一會，選定七千餘字，謂足敷中學以下之用，是編字數雖僅差十一，而普通士商用之，已綽綽有裕，惟去取之間，互有出入，一以切於實用為主。
- 是編專供識字之人於悤遽中檢查遺忘之字者，故祇備字而不詮義，其間間有相似而易於誤會如祛袪，唇脣等字，則特為注明。
- 是編既以粵音為主，除吾粵之俗字徹底錄出外，其餘普通之俗字，與本字易以辨別者如以凉為涼以婿為壻，以却為卻以况為況等，則祇收本字不另詮釋，至俗字之本字太生僻者，則於本字下註明俗作某字以清眉目。
- 粵之俗字，以單線為號，化學名字則加雙線為號，如𡰪|鈉||是也。
- 廣州市土話向分西關北關，北關與外省人雜處，故畧帶外省土白，而反與字書之音較近，如制台讀如至台，黌宮讀洪宮，西關人全用牙音，故 ch 與 ts 之音淆亂無別，是編專採北關（即城裏）土音，并將字書之音，細加校勘，非特易於檢查，且外縣人可從此練習市音也。
- 香島五方雜處，言語龐雜，雖以廣州市音為主，而外縣人之學語者，却乏牙音，是編雖分 ch 與 ts 兩門，如於 ch 部不能檢出之字當向 ts 部檢之。
- 字書有一字兩音而同義者，如箑音翣又音捷、又有一字兩音而異義者、如洒音洗雪也、又音灑汛也，均分別注釋。
- 普通粵音與字書之音相反者，如奢音賒讀作車音，翕音吸讀作揖音，靚音淨讀如嶺音，逮音代讀作弟音，芋音裕讀作戶音，標注尤不厭其詳。
- 番禺（非指部屬言）土音，最為複雜，凡之從 ng 音者，均不用鼻音，如我讀作柯上聲，脚讀作角，檢字時當特別注意。

# 併音法
 
此法創自粵中外人傳教師以便婦孺誦寫，共用字母十七箇，港中政府所併之街名人名等，均用是法，幾成為港政府規定之中文併音法，其中有未諳此道而隨意亂併者，均非正軌，故畧識英文者，練習數分鐘，便可了然於中矣，讀法如左。

作者簡介
--------
本書封面著名馮漢 (Fung Hon)，例言注有「鶴山馮 漢師韓編纂」。

根據《馮師韓先生書畫集》(1962) 資料，馮漢 (1875-1950)，字師韓，號鄧齋，晚號無沙老人，廣東省鶴山縣越塘村人。早年畢業於香港皇仁書院及天津北洋工學院，甲午戰爭後定居香港，曾任政府翻譯官、電影檢查官等職，其後從事教育。著有《漢字（說文）易檢》、《書法相人術》、《書法闡微》、《掌紋學大辭典》等書。

馮氏近照可參閲[香港浸會大學圖書館藝術館藏 Instagram 帳戶貼文](
https://www.instagram.com/p/CwhddXth0Zz/img_index=3?img_index=3)。


體例
--------
- 此書以粵語拼音據英文字母排序，由 “A” 到 “Y” 共六百多個音節。
- 單字在音節右邊列舉，全書不注聲調，也沒有為不同聲調以符號分隔。
- 雖然漢字大致以陰平、陽平、陰上、陽上、陰去、陽去、陰入（中入）、陽入為序，不過也有例外。同音節不同調的字只錄一次。所以，使用者無法從此書查得實際字調。
- 書中偶有為多音字注上釋義或詞例。

### 觀察

簡單而言，本書的注音系統跟十九世紀來華傳教士所採用的「早期粵音」系統相同，與現代粵音比較不同之處如下：

1. 塞擦音/擦音聲母分為「ts ts' s」（舌尖）和「ch ch' sh」（舌面）兩套（不過序者莫慧劍已指出此二組聲母相混情況）。
2. 有 om/op 韻，亦有 z 韻。
3. 韻母缺少複元音韻母 /ei/。
4. 「噓許去」等字韻母為 ü （國際音標：y），與「於余娛」等字韻母相同。

以上均為早期粵音特徵。

不過，此書「據、女、俱」韻母為 ui（國際音標 ɵy），不同於早期粵音文獻和 1937 年《中華新字典》王頌棠之 ü，與早期粵音作 ui 的「衰、堆、推、吹」韻母混同。
